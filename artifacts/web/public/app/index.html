१

डाउनलोड थिच्नुहोस्

Tap download

फाइल फोनको Downloads मा जान्छ। सकिएपछि त्यसैलाई थिच्नुहोस्।

The file lands in your Downloads. Tap it when it finishes.

२

अनुमति दिनुहोस्

Allow the install

फोनले “Allow from this source” सोध्न सक्छ। अनुमति दिनुहोस् — यो एक पटक मात्र सोध्छ।

Android may ask to “Allow from this source”. Turn it on — it only asks once.

३

Install थिच्नुहोस्

Tap Install

केही सेकेन्डमा सकिन्छ। त्यसपछि होम स्क्रिनमा आइकन देखिन्छ।

It takes a few seconds, then the icon appears on your home screen.

⚠️ चेतावनी देखिए नआत्तिनुहोस्

⚠️ If you see a warning, don't panic

फोनले यस्तो देखाउन सक्छ:

Your phone may show something like:

“Unsafe app blocked” / “Play Protect ले रोक्यो”

यो एप बिग्रेको भएर होइन। Play Store बाट नआएको जुनसुकै एपलाई Android ले यसै भन्छ। More details → Install anyway थिच्नुहोस्।

Nothing is wrong with the app. Android says this about every app that did not come from the Play Store. Tap More details, then Install anyway.

पत्याउन नसके पसलमा फोन गर्नुहोस् — तलको नम्बरमा।

If you would rather check first, call the shop on the number below.

डाउनलोड गर्न मन छैन? वेबसाइट फोनमै एप जस्तै राख्न सकिन्छ — यहाँ खोल्नुहोस् र ब्राउजरको मेनुबाट “Add to Home screen” रोज्नुहोस्।

Would rather not download? The website can sit on your home screen like an app — open it here and choose “Add to Home screen” from the browser menu. This is the only option on iPhone.
